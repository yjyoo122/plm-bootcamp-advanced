**Fusion Manageのゼロから構築**

Autodesk **Fusion Manage**（PLM）のハンズオン構築モジュールです。見るだけの講座ではありません。画面に沿って、自分のテナントで実際に作っていきます。

12の章を通して、リビジョン管理ワークスペース **Meeting Memos** を作り、それを動かす仕組みを組み上げます。ワークスペースの関係、ライフサイクルのマッピング、ワークフロー、前提条件フィルタ、そして4種類のスクリプトです。

## ▶ トレーニングを開く

モジュールは1つで、**2つの版**と**2つの言語**があります。お使いのテナントと受講者に合わせて、リンクを選んでください。

| | 日本語 | English |
|---|---|---|
| **Fusion 連携版** — Fusion ハブと連携した Fusion Manage | **[開く](https://yjyoo122.github.io/plm-bootcamp-advanced/?lang=ja)** | [Open](https://yjyoo122.github.io/plm-bootcamp-advanced/) |
| **スタンドアロン版** — Fusion Manage 単体 | **[開く](https://yjyoo122.github.io/plm-bootcamp-advanced/?lang=ja&ed=sa)** | [Open](https://yjyoo122.github.io/plm-bootcamp-advanced/?ed=sa) |

インストール、ログイン、ダウンロードは不要です。クリックすれば、ブラウザでそのまま動きます。

**モジュールの中でも切り替えられます。** ツールバーの［Fusion 連携版｜スタンドアロン版］と［English｜日本語］、またはキーボードの <kbd>E</kbd>（版）と <kbd>L</kbd>（言語）で切り替えます。見ているページはそのままです。アドレス バーも切り替えに合わせて変わるので、コピーしたリンクは同じ版と言語で開きます。

### どちらの版かを確認する

テナントの ☰ メニューを開いてください。

| ☰ メニューにあるもの | 版 | モジュールで変わるところ |
|---|---|---|
| ［PLM ロール］と［PLM 設定］ | **Fusion 連携版** | ロールは Fusion Manage で設定し、グループとユーザは **Fusion ハブ**で管理します |
| ［管理］（［ワークスペース マネージャ］、［セキュリティ］、［システム設定］） | **スタンドアロン版** | ロール、グループ、ユーザのすべてを、Fusion Manage の［管理］›［セキュリティ］で管理します |

ワークスペース、2つの接続、ワークフロー、前提条件フィルタ、スクリプトは、どちらの版でも同じ手順で作ります。スタンドアロン版には、メニューからの行き方とグループ作成のページが少し加わります（207ページに対して211ページ）。

### 日本語版について

すべてのページを、日本語の受講者向けに書いています。機械翻訳ではありません。

- **画面のラベル**は、日本語版 Fusion Manage の表記に合わせています（Autodesk の日本語ヘルプと日本語テナントで確認）。
- **画面写真**は英語版のままです。そのため、各ページで初めて出てくるラベルには、画面写真の英語表記を小さく併記しています。
- **受講者が入力する名前**（Meeting Memos、MEETING_DATE など）は、画面写真と同じ英語のままです。スクリプトもそのまま動きます。

> **先に[基礎編（Fundamentals）](https://github.com/yjyoo122/plm-bootcamp-fundamentals)を受講してください。** このモジュールは、ワークスペースとは何か、変更のプロセスがどう進むかを知っている前提で進みます。→ [基礎編を開く](https://yjyoo122.github.io/plm-bootcamp-fundamentals/)（英語のみ）

## バージョン

上のバッジには、今公開されているバージョンが常に表示されます。最新のリリースから直接読み込むので、古くなることはありません。2つの版と2つの言語は1つのファイルに入っているので、バージョンも常に共通です。

- **バージョンごとの変更点** → **[CHANGELOG.md](CHANGELOG.md)**（英語）
- **リリースの一覧と日付** → **[Releases](https://github.com/yjyoo122/plm-bootcamp-advanced/releases)**

以前に開いたことがある場合は、そのときのバージョンとバッジの数字を比べてください。数字が上がっていれば、モジュールが更新されています。<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> で再読み込みすると、最新の内容が表示されます。

バージョンが上がるのは、モジュール本体を公開し直したときです。README や講師用ガイドの修正では上がりません。

## 始める前に：テナントが必要です

手を動かしながら進めるモジュールです。講師メモにも、はっきりこう書いてあります。

> 自分のテナントで一緒に手を動かす受講者のほうが、見ているだけの受講者よりはるかに得るものが多い。

効果を得るには、**管理者権限のある自分の Fusion Manage テナント**が必要です。テナント全体に関わるものを設定する手順があるからです。たとえばロールは、Fusion 連携版では［PLM ロール］、スタンドアロン版では［管理］›［セキュリティ］で設定します。ワークスペース単位の権限だけでは足りません。

テナントがなくても、資料として読むことはできます。ただし、何も作れません。

## クイック スタート

1. 上の表から、自分のリンクを開きます。
2. <kbd>F</kbd> キーで全画面表示にします。
3. <kbd>→</kbd> キーか <kbd>space</kbd> キーで進みます。
4. <kbd>?</kbd> キーで、いつでもキーボード操作の一覧を表示できます。

講師の発表を見るのではなく、自分で読み進めるときは、<kbd>P</kbd> キーで［資料］モードに切り替えます。モジュール全体が、目次付きの1つのスクロール ページになります。別のウィンドウで作業しながら、前の手順を読み返すときに便利です。

## 動作環境

| | |
|---|---|
| **ブラウザ** | 最新の Chrome、Edge、Firefox、Safari |
| **インストール** | 不要 |
| **アカウント／ログイン** | 閲覧には不要 |
| **一緒に作るには** | 管理者権限のある Fusion Manage テナント |
| **インターネット** | 最初にページを読み込むときだけ |
| **画面** | プロジェクタ、モニタ、ノート PC。画面写真はウィンドウの大きさに合わせて表示されるので、ノート PC でも切れません。画面が2つあると便利です（片方にモジュール、もう片方にテナント） |

HTML ファイル1つで完結しています。サイズは約 16 MiB で、2つの版と2つの言語がすべて入っています。画面写真178枚と図13点はファイルに埋め込まれていて、外部からは何も読み込みません。一度開けば、ネットワークが切れても動きます。

## オフラインで使う

1. **[index.html](https://raw.githubusercontent.com/yjyoo122/plm-bootcamp-advanced/main/index.html)** をダウンロードします（右クリック →［名前を付けてリンク先を保存］、約 17 MB）。
2. ダブルクリックで開きます。Web サーバは不要で、ブラウザで同じように動きます。英語の Fusion 連携版で開くので、ツールバーか <kbd>E</kbd> キーと <kbd>L</kbd> キーで、版と言語を切り替えてください。

## 操作方法

### ツールバー

| ボタン | 動き |
|---|---|
| ☰ | 章の一覧 |
| ⌂ | 表紙に戻る |

### キーボード操作

| キー | 操作 |
|---|---|
| <kbd>→</kbd> / <kbd>space</kbd> / <kbd>PageDown</kbd> | 次へ。吹き出しも1つずつ表示します |
| <kbd>←</kbd> / <kbd>PageUp</kbd> | 戻る |
| <kbd>S</kbd> | 講師用ノート |
| <kbd>P</kbd> | ［発表］／［資料］の切り替え |
| <kbd>F</kbd> | 全画面表示 |
| <kbd>H</kbd> | 表紙に戻る |
| <kbd>M</kbd> | 章の一覧 |
| <kbd>E</kbd> | 版の切り替え（Fusion 連携版／スタンドアロン版） |
| <kbd>L</kbd> | 言語の切り替え（English／日本語） |
| <kbd>Esc</kbd> | メニュー、ノート、拡大した画像を閉じる |

画面写真はクリックすると拡大できます。設定ダイアログの画面が多いので、こまめに拡大するのがおすすめです。<kbd>Esc</kbd> で閉じます。

> **メモ：** <kbd>→</kbd> キーは、そのページの吹き出しを1つずつ表示してから、次のページに進みます。止まったように見えても、止まってはいません。

## 作るもの

| # | 章 | 内容 |
|---|---|---|
| 1 | **表紙** | タイトルと講師 |
| 2 | **考え方** | 2種類のワークスペースと、それをつなぐ1つの仕組み。この後のすべては、2つがつながる瞬間のための準備です |
| 3 | **Meeting Memos** | リビジョン管理ワークスペース。管理される側です。メモとそのすべてのリビジョンを持ち、自分では動きません |
| 4 | **アクセス権** | ロールが権限を、グループが人を持ちます。Fusion 連携版では、ロールは Fusion Manage、グループと人は Fusion ハブで設定します。スタンドアロン版では、3つとも［管理］›［セキュリティ］で設定します |
| 5 | **Memo Revision** | リビジョン ワークスペース。動かす側です。ワークフローを持ち、その［管理対象アイテム］タブが、もう一方のワークスペースのリビジョンを動かします |
| 6 | **2つの接続** | ［ワークスペースの関係］で「どのワークスペースを改訂できるか」を、ライフサイクルのマッピングで「どのライフサイクルの遷移を適用できるか」を決めます。どちらも必須で、**どちらが欠けても警告は出ません** |
| 7 | **ワークフロー** | ステータスは場所、遷移は動き。ステータスのパネルにある2つのチェック ボックスが、動きのすべてを決めます |
| 8 | **前提条件フィルタ** | ロールで対象者の範囲を決め、前提条件フィルタで、そのレコードの担当者1人に絞ります。コードは書きません |
| 9 | **スクリプト** | 4種類のスクリプトは、それぞれ違うタイミングで、違う問いに答えます。同じものの4つのバリエーションではありません |
| 10 | **オンデマンド** | 遷移を持たず、ユーザが実行するスクリプト。お客様固有の自動化の多くは、最終的にここに置かれます |
| 11 | **動作確認** | ここまで作ったすべてで、1つのメモをリリースし、改訂します。リリースされたリビジョンはロックされ、履歴が残ります |
| 12 | **まとめ** | 作ったもの、動かないときに最初に確認すること、書き留めておく価値のある3つのこと |

多くの人がつまずくのは第6章で、しかもエラーは出ません。原因をたどる順番は、第12章にまとまっています。
